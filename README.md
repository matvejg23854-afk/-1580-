# ✔️ Архитектура 3-й лабораторной работы
## 🔹 `main.py` отвечает за ввод
- мусорку функций ♿
- чистит данные
- не даёт ввести текст вместо числа
- работает с меню
- вызывает методы класса

## 🔹 Класс (`Planet`, `Book`) отвечает за
- хранение данных
- сравнение объектов
- логику объекта
- магические методы (`__str__`, `__repr__`, `__lt__` и т.д.)

## ✔️ Разделение ответственности

### `main.py`
> "Интерфейс" программы и работа с пользователем

### Класс
> Модель объекта и его поведение
