# ✔️ Архитектура лабы 3

## 🔹 `main.py`
- Точка входа в программу.  
- Запускает главное меню приложения.

## 🔹 `menu.py`
Отвечает за интерфейс программы:
- вывод меню
- навигацию
- взаимодействие с пользователем
- вызов функций обработчика

## 🔹 `handler.py`
Отвечает за работу с данными:
- CRUD-операции
- поиск
- сортировку
- загрузку/сохранение файлов
- экспорт CSV

## 🔹 `Planet`
Модель объекта и бизнес-логика:
- хранение данных планеты
- валидация данных
- магические методы
- сравнение объектов
- поведение объекта
